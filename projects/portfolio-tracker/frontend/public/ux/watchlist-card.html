1. Vue d'ensemble

Évolution des cartes existantes sur /watchlist-v2. L'information s'ajoute en couches successives selon le stade de l'entreprise, sans surcharger les cas simples.

Principe : une carte watchlist sans position ouverte n'affiche que le readiness badge. Une carte avec position ouverte affiche le thermomètre. Une carte avec plan de sortie actif affiche les tranches.

5. Position active — Thermomètre de valorisation

Sur les cartes en statut "portfolio" (position ouverte). La barre de prix montre la position du cours actuel par rapport à la fourchette de valeur intrinsèque.

Position active — Zone étiré
┌─────────────────────────────────────────────────────────────────────┐ │ NVDA Nvidia Corporation Portfolio active │ │ 45 actions · Entrée : $89.00 · Actuel : $118.42 · +33% +$13k │ │ ───────────────────────────────────────────────────────────────── │ │ │ │ ▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓░░░░░░░░░░░░░░░░░░░ 🟠 Étiré │ │ $95 IV basse $118 actuel $130 IV haute $150 ⚡ Alerte │ │ │ │ 📅 Earnings Q3 — dans 23 jours │ │ Hypothèses : H1 ✅ H2 ✅ H3 ⚠ à surveiller H4 ✅ H5 ✅ │ │ │ │ [→ Suivi de thèse] [→ Page de décision] │ └─────────────────────────────────────────────────────────────────────┘

Les 4 zones du thermomètre :

🟢 Attractif Prix < IV basse → suggère renforcement
🟡 Juste prix IV basse ≤ Prix ≤ IV haute → maintenir
🟠 Étiré IV haute < Prix ≤ seuil alerte → vigilance, pas de renforcement
🔴 Surévalué Prix > seuil alerte (IV haute × 1.15) → sortie progressive déclenchée

Questions ouvertes — à trancher avant implémentation

  1. Thermomètre toujours visible (proposé) ou dépliable via un chevron pour réduire la hauteur de carte ?
  2. Tri de la watchlist : par readiness (🟢 en haut, proposé) ou par ordre d'ajout (comportement actuel) ? Filtre manuel possible ?
  3. Notification MVDD → 🟢 : Slack + badge vert mis à jour silencieusement (proposé), ou aussi un toast dans l'UI si la page est ouverte ?
  4. Hypothèses sur la carte : liste courte H1 ✅ H2 ✅ H3 ⚠ (proposé) ou seulement un résumé compact 4/5 hypothèses ok + lien ?
  5. Carte trop chargée ? La position active avec thermomètre + tranches est dense. Faut-il un mode compact et un mode détaillé au clic ?
  6. Alerte seuil franchi : notification Slack (déjà prévu) + bordure rouge clignotante sur la carte (proposé) ou seulement le badge 🔴 ?
