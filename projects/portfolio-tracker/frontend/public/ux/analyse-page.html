1. Vue d'ensemble

Nouvelle page remplaçant /ticker/{id}/opportunity. Layout 3 panneaux fixes (knowledge left · chat center · result right). C'est le cœur du flux d'analyse V2.

Principe d'isolation : les deux contextes bull/bear sont physiquement séparés — le bear-agent ne reçoit jamais le bull case comme input. L'UX doit rendre cette isolation évidente et rassurante.

La barre de progression en bas de page montre l'avancement global : Bull → Bear → Synthèse. Chaque étape déverrouille la suivante.

Questions ouvertes — à trancher avant implémentation

  1. 3 colonnes sur mobile : empilées verticalement (chat en haut, résultat en bas) — ok ? Ou faut-il une vue tabs sur mobile ?
  2. Isolation visuelle : le 🔒 sur l'onglet Bear est-il suffisant ? Ou faut-il un bandeau explicite plus visible pendant la génération du bull ?
  3. Modification du bull case : champs éditables inline dans le panneau droit (proposé) ou modal/drawer séparé ?
  4. Tool calls dans le chat : visibles comme lignes d'activité (proposé) ou dans un toggle "Voir les recherches effectuées" pour ne pas alourdir le chat ?
  5. Barre de progression : en bas de page (proposé) ou en haut sous le header ticker ?
  6. Conversation libre : peut-on envoyer un message libre à l'agent pour guider l'analyse, ou la session est-elle entièrement automatique (agent → résultat → modification manuelle) ?
