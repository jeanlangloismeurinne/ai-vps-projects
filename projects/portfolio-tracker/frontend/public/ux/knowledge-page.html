1. Vue d'ensemble

Nouvelle page accessible depuis la watchlist ("Explorer la connaissance") ou la fiche ticker. Sert de fenêtre complète sur tout ce que le système sait sur une entreprise : sources, fiabilité, questions ouvertes, documents ingérés.

Objectif : l'utilisateur doit pouvoir en 2 minutes comprendre sur quoi reposent les analyses et identifier ce qui manque.

Correspond au pattern Karpathy (LLM Wiki) : cette page rend le wiki cumulatif navigable par l'humain. Les onglets correspondent aux fichiers index.md, profile.md, financials.md, competitive.md du repo.

2. Header — badge readiness

Le header est identique quel que soit l'onglet actif. Le badge readiness est le signal central.

État : Prêt pour l'analyse
┌───────────────────────────────────────────────────────────────────────┐ │ ← Retour NVDA — Nvidia Corporation $118.42 ↑ +2.3%│ │ ───────────────────────────────────────────────────────────────────── │ │ 🟢 Prêt pour l'analyse · 34 entrées · Confiance 74% · Lint ✅ │ │ │ │ [Index] [Profil] [Financiers] [Concurrence] [Documents] [⚠ 3] │ └───────────────────────────────────────────────────────────────────────┘

Variantes du badge

🟢 Prêt pour l'analyse · 34 entrées · Confiance 74% MVDD complet · Lint OK
🟡 Pipeline en cours · 3/5 items MVDD Estimation : 4 min
🔴 MVDD incomplet · 1 item bloquant manquant Analyse bloquée
⚫ Too hard Informations insuffisantes avec sources publiques
Le badge [⚠ 3] sur l'onglet "À vérifier" indique le nombre d'entrées en attente de validation humaine (llm_memory non reviewées + conflits détectés par le lint).

Questions ouvertes — à trancher avant implémentation

  1. Navigation : onglets horizontaux (proposé) ou sidebar verticale à gauche ? Sur mobile les onglets horizontaux peuvent être trop nombreux (6 tabs).
  2. Densité de l'Index : 4 items/catégorie + "voir plus" (proposé) ou tout afficher avec barre de recherche/filtre en haut ?
  3. Entrées llm ⚠ : badge dans l'Index (proposé) + dans "À vérifier", ou seulement dans "À vérifier" pour ne pas surcharger l'Index ?
  4. Ajout d'une entrée manuelle : formulaire inline dans l'Index ou modal séparé ?
  5. Bouton "Analyser" : présent dans ce header (proposé) ou seulement depuis la watchlist ?
  6. Accès depuis la page Thèse : panneau latéral rétractable pointant vers /knowledge, ou lien simple vers la page ?
